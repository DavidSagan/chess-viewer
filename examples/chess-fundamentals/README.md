The text is from the [Project Gutenberg edition](https://www.gutenberg.org/ebooks/33870), which is
listed as public domain in the USA. Copyright rules differ between countries. Descriptive notation
was converted to algebraic, and page references in the notes are to the book.

To rebuild a game, run this from this folder:

```bash
python3 ../../tools/chessbook.py game-01-marshall-capablanca.tex
```
